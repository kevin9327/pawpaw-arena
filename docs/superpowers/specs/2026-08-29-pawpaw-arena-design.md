# 멍냥아레나 (PawPaw Arena) — 디자인 스펙

날짜: 2026-08-29 · 상태: 사용자 승인됨 · 접근: A안(바닐라 JS + Canvas + Node `ws`)

## 목표

귀여운 동물들이 싸우는 초간단 2D .io 아레나 슈터. 접속한 실제 유저들끼리 한 방에서
싸우고, 부족한 자리는 봇이 채운다. 서버가 없거나 잠들어 있어도 봇 모드로 즉시 플레이
가능(하이브리드). 데스크톱 브라우저 우선. 유지비 0원 배포.

## 코어 루프

- 탑다운 2D 아레나 **2,500×2,500**, 밝은 잔디 격자 배경, 외곽은 벽.
- 입장 화면: 닉네임 입력 + 동물 3종 중 선택.
- 맵에 **간식(사료 알갱이)** 상시 스폰(목표 150개 유지, 개당 XP 5) → 먹으면 XP.
  상대 처치 시 상대 누적 XP의 30%를 즉시 획득.
- 레벨 필요 XP: `40 × 1.35^(레벨-1)` (레벨 1→2가 40). 레벨업 시 **3택 1 업그레이드**:
  공격력 / 연사속도 / 이동속도 / 최대체력 4종 중 랜덤 3개 제시, 각 스탯 최대 5단계
  (단계당 해당 스탯 +15%).
- 사망: 보유 XP의 50%를 간식으로 주변에 뿌리고 3초 뒤 리스폰(레벨 초기화).
- UI: 우측 상단 리더보드 톱10(점수=누적 XP), 상단 킬 피드, 하단 중앙 체력바+레벨.

## 동물 (밸런스 초기값 — 구현 중 플레이테스트로 조정 가능)

| | 이동속도 | 최대체력 | 발사체 | 데미지 | 연사(발/초) | 탄속 |
|---|---|---|---|---|---|---|
| 🐱 고양이 | 220 | 80 | 털뭉치(소) | 8 | 5 | 500 |
| 🐶 강아지 | 190 | 100 | 뼈다귀(중) | 14 | 3 | 450 |
| 🐷 돼지 | 160 | 140 | 도토리(대) | 24 | 1.5 | 400 |

단위: px/s, 체력점. 몸 반지름 기본 22px, 레벨에 따라 +최대 8px.

## 봇

- 방 인원(유저+봇)이 항상 **12명**이 되도록 서버가 봇을 충원/제거.
- 상태기계: **배회**(가까운 간식으로 이동) → **교전**(시야 700px 내 적: 상대 속도를
  반영한 예측 조준 + 이동 지그재그) → **도주**(체력 30% 미만: 적 반대 방향).
- 실력 편차: 봇마다 조준 오차(0.05~0.4rad)·반응 지연 랜덤 → 쉬운 봇/무서운 봇 혼합.
- 닉네임 풀(초코, 마루, 꿀꿀이, 나비, 보리, Mochi, Biscuit, Waffle, …)과 랜덤 동물.
- 동일 AI 코드를 서버(온라인 방)와 클라(오프라인 모드)가 공유한다.

## 넷코드·하이브리드

- 권위 서버: 서버가 **30Hz 고정 틱**으로 시뮬레이션. 클라는 입력만 보냄.
- 클라→서버 (30Hz, JSON): `{t:"input", seq, move:[dx,dy], aim, fire}`
- 서버→클라 (20Hz, JSON): `{t:"state", tick, players:[...], bullets:[...], pellets:[...]}`
  전체 상태 브로드캐스트(방 최대 12엔티티라 충분). 입장 시 `{t:"welcome", id, config}`,
  이벤트성 `{t:"kill"|"levelup"|...}`.
- 클라 렌더: 스냅샷 **100ms 보간**. 클라 예측 없음(v1 단순 우선).
- 하이브리드 흐름: 로드 → WS 3초 연결 시도 → 실패 시 **봇 모드 즉시 시작**(shared
  시뮬을 브라우저에서 구동) + 10초 간격 백그라운드 재연결 → 성공 시 "온라인 방 입장"
  버튼 노출 → 클릭하면 온라인 방에 새로 스폰.

## 아트·사운드

- Canvas 벡터로 직접 그린 동물: 원형 몸 + 귀 + 눈/코/입, 조준 방향으로 회전.
  파스텔 팔레트. 피격 시 흰색 플래시, 사망 시 뿅 파티클, 간식 섭취 반짝임.
- WebAudio 합성 효과음(발사 뿅, 피격, 레벨업, 사망). 외부 에셋 파일 없음.

## 코드 구조

```
petaflo-arena/
  shared/    # 시뮬 코어: 물리·충돌·성장·봇AI·상수 (ESM, 서버·클라 공용)
  client/    # index.html + js/ (렌더, 입력, 넷, 보간, 오프라인 모드) — 빌드 도구 없음
  server/    # Node + ws: 방 관리, 30Hz 틱 루프, 로컬 개발용 정적 서빙
  docs/superpowers/specs|plans/
```

- Node ESM(`"type":"module"`)으로 shared를 양쪽에서 그대로 import.
- 의존성은 서버의 `ws` 단 하나. 클라이언트 의존성 0.

## 배포

- GitHub 저장소(계정 kevin9327) 신규 생성.
- 클라: **GitHub Pages** (항상 켜짐, 즉시 로드).
- 서버: **Render 무료 웹서비스** (`render.yaml` 포함; Render 가입·저장소 연결은
  사용자가 직접). 15분 유휴 시 슬립 → 깨어나는 30~50초는 봇 모드가 커버.
- 클라의 서버 주소는 `client/js/config.js` 한 곳에서 관리.
- 로컬 개발: `node server` 하나로 정적 서빙+WS 모두 제공.

## 테스트

- shared 시뮬 코어: `node --test` 유닛테스트 — 이동/충돌, 탄-플레이어 판정, 데미지·
  사망·XP 드랍, 레벨업·업그레이드 적용, 봇 상태 전이·예측 조준.
- 온라인 동기화: 로컬 서버 + 브라우저 2탭 수동 검증(서로 보이고, 쏘고, 죽는지).
- 오프라인 모드: 서버 내리고 페이지 로드 → 봇 모드 자동 시작 확인.
